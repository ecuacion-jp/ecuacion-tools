# ecuacion-tool-housekeep-files

## What is it?

`ecuacion-tool-housekeep-files` is a batch tool that performs routine file and directory management (housekeeping) tasks based on an Excel configuration file.

- It performs file operations — copy, move, delete, compress, decompress — based on rules defined in an Excel file.
- It supports file transfer with remote servers via SFTP, in addition to the local filesystem.
- It processes only files matching wildcard path patterns and older than a configured number of days.
